##### 运算符  (针对基本类型变量)

| **运算符** | **含义** |
| ---------- | -------- |
| **&**      | 按位与   |
| **\|**     | 按位或   |
| **^**      | 按位异或 |
| **~**      | 按位取反 |
| **<<**     | 左移     |
| **>>**     | 右移     |

##### 在不改变其它位的情况下对某几个位进行设值

```
//比如改变GPIOA状态
GPIOA->CRL &= 0XFFFFFF0F;    //将第4~7位清0
//然后再与需要设置的值进行|或运算:
GPIOA->CRL |= 0X00000040;    //设置相应位的值(4) 不改变其他位的值
```

##### 移位操作提高可读性

```
SysTick->CTRL |= 1 << 1;  //将CTRL寄存器的第一位设置为1 (1 << 1: 0000 0010)
SysTick->CTRL |= 0X0002;  //也可以实现 但可读性稍差
```

##### 清除某位

```
SysTick->CTRL &= ~(1 << 0) ;    //关闭 SYSTICK
```

##### 按位异或操作

```
GPIOB->ODR ^= 1 << 5;  //相当于使GPIOB->ODR第5位取反
```

##### 条件编译

```\
//#ifdef当标识符被定义过时执行程序段1
#ifdef 标识符
  程序段 1
#else
  程序段 2
#endif

//#ifndef当标识符没有被定义过时执行程序段1
#ifndef 标识符
  程序段 1
#endif

//#if !define(...)  !define()是一个条件表达式返回值为1或0
#if !defined(SOME_MACRO)  
  #define HSE_VALUE 24000000U  
#endif
```

**注** U无符号整型 UL无符号长整型 F浮点型 (不区分大小写)

```
struct Person *ptr = &person2;

```

##### 结构体成员的内存分配与对齐

理论上 结构体所占用的存储空间是各个成员变量所占的存储空间之和 但是为了提高CPU的访问效率 采用了内存对齐方式:

(1)结构体的每一个成员起始地址必须是自身类型大小的整数倍

(2)结构体大小必须是结构体占用最大字节数成员的整数倍

```
struct test 
{ 
    char a;
    int b;
    float c;
    double d;
}mytest;
//假设1B为一个地址 char占1B int占4B(起始地址需要为4所以char被扩展到4B) float4B double8B 总24B是最大8B的整数倍
```

##### volatile

强制编译器减少优化 告诉编译器必须每次去内存中取变量值而不是去保存了数据的寄存器取

```
#define __I volatile
#define __O volatile
#define __IO volatile
#define __IM volatile const  //const是软件层面只读无法修改 但硬件层面上可以修改
#define __OM volatile
#define __IOM volatile
```

##### static

###### 修饰局部变量

```
int add(){
	static int a;  //不改变作用域 但延长变量a的生命周期 在add()被销毁后a的值依旧存在数据段或BSS段 下一次调用add()不会再初始化a而是使用上一次留下来的a值
	...
}
```

###### 全局静态变量

```
static int a;  //作用域不变 生命周期不变 但外部文件无法使用extern访问
int main(){}
```

###### 静态函数

```
static void add(){}  //外部文件无法通过extern访问
```

**注**  c不支持函数套函数 c++、java同样 但它们有一个lambda表达式可实现相同效果  python、go、rust、js等可定义函数套函数 但从外部访问时只有python和go能通过"闭包"的形式访问

###### 静态初始化

尽管这不是static的直接用途 但它在静态初始化中扮演了重要角色 当全局变量或静态变量被声明并赋予初值时 编译器会确保在程序开始执行之前进行初始化 这通常是在main()函数之前发生的

##### STM32 (默认无os)

|      |      | 物理介质 |
| :--- | :--: | :----:  |
| 代码段 | 编译后的机器指令 const修饰的常量 | Flash |
| 数据段 | 已初始化的全局变量、静态变量 | RAM |
| BSS段 | 未初始化的全局变量、静态变量 | RAM |
| 堆 | malloc或new申请的内存空间 | RAM |
| 栈 | 函数参数、返回地址、局部变量 | RAM |

**注** 运行时从Flash取出至RAM
